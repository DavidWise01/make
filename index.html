The Program

born · what it does · the line

Born
Bell Labs · 1976

Stuart Feldman wrote it after a colleague kept shipping broken builds — a tool to rebuild exactly, and only, what needed it.

What it does
rebuild what changed

Read a Makefile of targets and dependencies; figure out what is out of date and rebuild it, in order — automation for assembling software.

The line
make → every build system

The ancestor of every build tool — cmake, ninja, bazel, npm scripts — all the children of one file of rules.
